LITTLE FIGURES STUDIO 3.1 - WINDOWS

UPGRADE AN EXISTING INSTALLATION
Save important projects and close the old launcher for this first update.
Put "Update Little Figures.bat" beside "Start Little Figures.bat", then
open the update shortcut. Keep using the same folder. Your models, private
Python environment and saved files stay in place. Later updates can stop
and restart the local app automatically when generation/analysis is idle.
The updater keeps app-file backups in .local/updates/backups.

START
1. Double-click "Start Little Figures.bat".
2. If prompted, install Python 3.12 and reopen the launcher.
3. Keep the launcher open while dependencies and local models download.
   Model downloads total about 255 MiB on first setup.
4. Your browser opens when ready. Choose "Open the studio".

MAKE YOUR GROUP
1. Upload one clear group photo (up to six people).
2. Review numbered detection outlines and the person count. The outlines are
   detection indicators, not crops of the future model.
3. If someone is missing, mark their body using "Someone is missing".
4. Confirm everyone is included, then choose "Generate whole group".
5. Inspect poses/details, set size, choose figure bases or a shared pedestal,
   then regenerate and download. New photo groups have round bases by default.

Visible poses, broad clothing shapes, and recognized accessories come from the
photo. Unclear clothing is automatically estimated and clearly labeled. Hems,
cuffs, lapels, folds, small noses and accessory details are actual 3D surfaces.
There are no pose or accessory menus. Everyone is generated/exported together.
If a person or major detail cannot be reconstructed, read the on-screen notes.
Difficult, cropped, overlapping, or small subjects may need a clearer photo.
This is a simplified figurine interpretation, not an exact scan.

No Node.js, account, hosting subscription, GPU, or paid API is required.
Photos stay on this computer. Saved/shared files exclude the original photo.
Explicitly save important projects; browser autosave is not a cloud backup.
STL has no units: select millimeters in your slicer and review print supports.

The app and launcher are tested on Linux. Native Windows execution has not
been tested here. If setup fails, copy the launcher error back into the chat.
